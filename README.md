## Sobre mim

Sou Wallace Gabriel. Neste perfil, compartilho projetos e estudos em qualidade de software, automação de testes e desenvolvimento de aplicações.

Meu foco é transformar regras de negócio em cenários verificáveis, investigar falhas e construir testes que ajudem a detectar defeitos. Também estudo desenvolvimento para compreender melhor os sistemas que testo, da API à interface.

## Projetos de QA

| Projeto | O que você encontra |
| :--- | :--- |
| **[QA Automation Lab](https://github.com/wallacinhochan/qa-automation-lab)** | Laboratório de qualidade com Cypress e TypeScript, testes de API e interface, planejamento de testes e ambiente local com Docker. |
| **[Desafio QA — VLAB](https://github.com/wallacinhochan/desafio-qa-vlab)** | Auditoria de um sistema educacional com defeitos intencionais: exploração, cenários BDD, relatórios de bugs e automação com Cypress. |
